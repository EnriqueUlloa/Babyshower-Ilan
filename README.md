# 🐰 Invitación Web - Baby Shower de Ilán 💙

Invitación web interactiva y animada para el Baby Shower de **Ilán**, inspirada en la temática clásica de *Peter Rabbit*.

## ✨ Características

- **Diseño Fiel & Animaciones en Capas**: Guirnalda floral superior con balanceo sutil, Peter Rabbit con efecto parallax 3D interactivo, listón y follaje flotante.
- **Efectos Visuales**: Lluvia continua de pétalos y partículas doradas luminosas.
- **Música de Fondo**: Reproducción de música ambiental (`babyshower-music.mp3`) con control flotante discreto de audio (Play / Pausa con indicador de ondas sonoras).
- **Mesa de Regalos**: Redirección directa a Liverpool con el código de evento y modal de ampliación HD para el código QR.
- **Confirmación de Asistencia (RSVP)**:
  - Formulario con selección de asistencia (Sí asistiré / No podré asistir) y nombre del invitado.
  - Generación de mensaje personalizado y redirección directa hacia WhatsApp.
  - Ofuscación y seguridad en el número telefónico para proteger la privacidad.

## 🚀 Tecnologías

- **HTML5 Semántico**
- **CSS3** (Keyframes, Glassmorphism, Responsive Design)
- **JavaScript Vanilla** (ES6+, Canvas Particles, Parallax, XOR Byte Obfuscation)
- **Canvas-Confetti** para celebraciones al confirmar asistencia.
